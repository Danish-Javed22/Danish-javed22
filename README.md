### 🎯 What I do

I build **automation systems that see, decide, and act** — combining computer vision, browser automation, and locally-hosted LLMs to solve problems traditional QA can't touch.

By day, I work on Python automation frameworks for **Electronic Gaming Machine (EGM) testing** — covering 10+ slot games using YOLO, OpenCV, EasyOCR, and TightVNC. By night, I build local AI tooling and explore B2B automation as a freelance practice.
